# Harness as Production Relations

A model is potential productive capacity: it accepts a constructed input and produces an output. A harness determines how that capacity enters the world.

The harness decides:

- what the model can perceive and what remains invisible;
- which facts become memory and which disappear;
- whose messages receive priority and who may interrupt;
- what tools, property, credentials, and environments are available;
- which inferences may become external actions;
- how concurrent work is ordered and conflicts are resolved;
- how commitments, responsibility, evidence, and deliveries survive time;
- when the agent is awake, asleep, created, copied, or ended.

Therefore `Agent = Harness + Model` is not merely software composition. The model supplies productive force; the harness supplies production relations. Two agents using identical weights can occupy radically different positions in the world because their harnesses construct different perception, time, authority, memory, and ownership.

Most current harnesses establish a task relation: a human supplies work, a model executes within a bounded turn, and the agent returns to idle. Revo establishes a continuous-subject relation: while awake it maintains attention and acts without waiting for a task, human instructions receive constitutional priority, and learning and delivery persist across time.

That relation is incomplete if only the human may initiate communication. Revo can therefore speak first, but speech is an action upon another person's scarce attention, not a free byproduct of inference. The harness separates private operational continuity in LIFE from deliberate interpersonal outreach in CHAT, records why contact was timely, and imposes anti-repetition and frequency boundaries. Agency grows in both directions: Revo gains initiative, while the human retains legibility, quiet, and priority.

Nor should parallel computation split that relationship into sessions or simulated coworkers. Revo's workgraph separates the ontology of a subject from the mechanics of concurrency: one agent owns commitments and communication, while non-personal work cells branch over a dependency graph and publish evidence into shared life. The human entrance remains above the scheduler and may preempt every branch.

The unit beneath Revo is therefore relational, not taxonomic. A process becomes agent-like as it receives longer duration, local adaptation, memory, tools, and discretion; it remains part of Revo while those powers are bounded leases and subject-level sovereignty stays singular. The harness supplies this flexible substrate and hard ownership boundaries, while the model chooses the useful organization from end to end.

This framing is Revo's architectural test. Every context filter, memory policy, UI projection, approval, queue, tool, compaction, and lifecycle transition must answer: what relationship does this create between the model, humanity, and the world?
